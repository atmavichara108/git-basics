# Каталог специальностей для строительства комплекса по переработке отходов

> Файл собирается автоматически из [`roles.csv`](roles.csv) скриптом `tools/build_docs.py`.
> Правки вносить в `roles.csv`, затем запускать скрипт.

Это **типовой** перечень: кто может понадобиться на таком объекте по этапам строительства.
Реальная потребность — только после ответа компании (таблица-заявка). Требования к документам —
типовые, их нужно сверять с требованиями компании и заказчика. Рыночные ориентиры — из открытых
объявлений, подробности и источники — в [`reference/market_rates.md`](../reference/market_rates.md).

Всего специальностей: **46** по **10** этапам.

## Оглавление

- **1. Подготовительные и земляные работы** — Машинист экскаватора, Машинист бульдозера, Машинист фронтального погрузчика, Машинист катка, Водитель самосвала, Геодезист, Разнорабочий / подсобный рабочий
- **2. Металлоконструкции (каркасы корпусов)** — Монтажник металлоконструкций (МК), Электросварщик / электрогазосварщик (НАКС), Стропальщик, Машинист крана (автокран, гусеничный, башенный), Такелажник, Газорезчик, Маляр по антикоррозийной защите / огнезащите
- **3. Стены, кровля, ворота** — Монтажник сэндвич-панелей, Кровельщик (профлист / ПВХ-мембрана), Промышленный альпинист, Монтажник ворот, окон и дверей
- **4. Бетон, полы, общестрой** — Бетонщик промышленных полов, Арматурщик / опалубщик, Каменщик, Плотник, Отделочник
- **5. Внутренние инженерные системы** — Электромонтажник, Монтажник кабельных линий (кабельщик), Монтажник слаботочных систем, Монтажник вентиляции (ОВиК), Сантехник / монтажник водоснабжения, канализации, отопления, Монтажник систем пожаротушения, Электромонтажник-наладчик / наладчик КИПиА
- **6. Наружные сети** — Монтажник наружных сетей (водопровод, канализация, ливнёвка), Сварщик полиэтиленовых труб, Бригада ГНБ (горизонтально-направленное бурение)
- **7. Технологическое оборудование** — Слесарь-монтажник технологического оборудования, Слесарь-ремонтник / механик
- **8. Полигон «хвостов» и площадки компостирования** — Укладчик геосинтетических материалов, Сварщик геомембраны
- **9. Дороги, площадки, благоустройство** — Дорожный рабочий / асфальтобетонщик, Машинист асфальтоукладчика / автогрейдера, Монтажник ограждений
- **10. ИТР и обслуживание** — Прораб / мастер СМР, Инженер ПТО, Специалист по охране труда, Кладовщик / снабженец, Водитель вахтового автобуса / микроавтобуса, Охранник

## 1. Подготовительные и земляные работы

### Машинист экскаватора

- **Что делает:** Котлованы и траншеи, планировка, погрузка грунта
- **Документы и допуски (типовые):** Удостоверение тракториста-машиниста нужной категории (гусеничный — «E», колёсный — «C»/«D»), свидетельство о профессии
- **Как проверить:** Фото удостоверений; на какой технике работал (марки, вес); пробная смена
- **Запросы для поиска:** `машинист экскаватора`, `экскаваторщик`
- **Ориентир по рынку:** нет данных — уточнить
- **Уточнить у компании:** Своя техника компании или нужна аренда с экипажем

### Машинист бульдозера

- **Что делает:** Планировка площадки, отсыпка, перемещение грунта
- **Документы и допуски (типовые):** Удостоверение тракториста-машиниста кат. «E», свидетельство о профессии
- **Как проверить:** Фото удостоверений; опыт планировки по отметкам/GPS
- **Запросы для поиска:** `машинист бульдозера`, `бульдозерист`
- **Ориентир по рынку:** нет данных — уточнить

### Машинист фронтального погрузчика

- **Что делает:** Погрузка и перемещение сыпучих материалов
- **Документы и допуски (типовые):** Удостоверение тракториста-машиниста кат. «C» или «D» (по мощности машины)
- **Как проверить:** Фото удостоверений
- **Запросы для поиска:** `машинист фронтального погрузчика`
- **Ориентир по рынку:** нет данных — уточнить

### Машинист катка

- **Что делает:** Уплотнение грунта, щебня, асфальта
- **Документы и допуски (типовые):** Удостоверение тракториста-машиниста нужной категории
- **Как проверить:** Фото удостоверений
- **Запросы для поиска:** `машинист катка`, `катковщик`
- **Ориентир по рынку:** нет данных — уточнить

### Водитель самосвала

- **Что делает:** Перевозка грунта, песка, щебня
- **Документы и допуски (типовые):** Водительское удостоверение кат. «C» (тягач с полуприцепом — «CE»)
- **Как проверить:** Права, стаж, опыт на стройке/карьере
- **Запросы для поиска:** `водитель самосвала`, `водитель кат C`
- **Ориентир по рынку:** нет данных — уточнить
- **Уточнить у компании:** Машины компании или нужны перевозчики со своими самосвалами

### Геодезист

- **Что делает:** Разбивка осей, контроль отметок, исполнительные съёмки
- **Документы и допуски (типовые):** Профильное образование или опыт; работа с тахеометром/GNSS
- **Как проверить:** Объекты в резюме, пробное задание
- **Запросы для поиска:** `геодезист строительный`, `геодезист на стройку`
- **Ориентир по рынку:** нет данных — уточнить
- **Уточнить у компании:** Чьё оборудование

### Разнорабочий / подсобный рабочий

- **Что делает:** Вспомогательные работы, погрузка-разгрузка, уборка, помощь бригадам
- **Документы и допуски (типовые):** Без специальных требований; медосмотр
- **Как проверить:** Короткое интервью, пробная смена
- **Запросы для поиска:** `разнорабочий`, `подсобный рабочий`, `подсобник на стройку`
- **Ориентир по рынку:** ≈3 500–4 000 ₽/смена; 75–160 тыс. ₽/мес (объявления Авито, СПб и ЛО, 2026)
- **Уточнить у компании:** Самая массовая позиция — хорошо ищется через Авито и местные группы

## 2. Металлоконструкции (каркасы корпусов)

### Монтажник металлоконструкций (МК)

- **Что делает:** Сборка и монтаж колонн, ферм, балок, связей, прогонов; болтовые соединения
- **Документы и допуски (типовые):** Свидетельство о профессии (разряд 3–6), удостоверение стропальщика, допуск к работам на высоте; желательно — навыки сварки
- **Как проверить:** Фото удостоверений; какие здания монтировал, вес элементов, высота; пробная смена
- **Запросы для поиска:** `монтажник металлоконструкций`, `монтажник МК`, `монтажник ангаров`, `монтажник стальных конструкций`
- **Ориентир по рынку:** вахта ≈150–250 тыс. ₽/мес на руки; ≈3 500–5 500 ₽/смена (объявления СПб/ЛО, 2026)
- **Уточнить у компании:** Часто работают бригадами с бригадиром и инструментом; оплата бывает за тонну

### Электросварщик / электрогазосварщик (НАКС)

- **Что делает:** Сварка металлоконструкций, закладных, узлов
- **Документы и допуски (типовые):** Аттестация НАКС (для МК — группа «СК», способы РД и/или МП), разряд 4–6
- **Как проверить:** Проверка удостоверения в реестре НАКС; пробный шов/допускные образцы
- **Запросы для поиска:** `сварщик НАКС СК`, `электросварщик РД`, `сварщик полуавтомат МП`
- **Ориентир по рынку:** ≈7 000–9 000 ₽/смена; ≈240–300 тыс. ₽/мес на руки (объявления СПб/ЛО, 2025–2026)
- **Уточнить у компании:** Какие группы и способы нужны; дефицитная позиция

### Стропальщик

- **Что делает:** Строповка и перемещение грузов краном
- **Документы и допуски (типовые):** Удостоверение стропальщика, актуальная проверка знаний
- **Как проверить:** Фото удостоверения и даты последней проверки знаний
- **Запросы для поиска:** `стропальщик`
- **Ориентир по рынку:** нет данных — уточнить
- **Уточнить у компании:** Часто совмещается с монтажником

### Машинист крана (автокран, гусеничный, башенный)

- **Что делает:** Подъём и монтаж конструкций и оборудования
- **Документы и допуски (типовые):** Удостоверение машиниста крана нужного вида; для автокрана — права кат. «C»
- **Как проверить:** Документы; на кранах какой грузоподъёмности работал
- **Запросы для поиска:** `машинист автокрана`, `крановщик`, `машинист гусеничного крана`
- **Ориентир по рынку:** нет данных — уточнить
- **Уточнить у компании:** Краны компании или аренда с экипажем

### Такелажник

- **Что делает:** Перемещение и установка тяжёлого оборудования и конструкций
- **Документы и допуски (типовые):** Удостоверение стропальщика; опыт такелажных работ
- **Как проверить:** С каким оборудованием работал
- **Запросы для поиска:** `такелажник`
- **Ориентир по рынку:** нет данных — уточнить
- **Уточнить у компании:** Понадобится при монтаже технологического оборудования

### Газорезчик

- **Что делает:** Резка металла
- **Документы и допуски (типовые):** Удостоверение газорезчика
- **Как проверить:** Фото удостоверения
- **Запросы для поиска:** `газорезчик`
- **Ориентир по рынку:** нет данных — уточнить

### Маляр по антикоррозийной защите / огнезащите

- **Что делает:** Окраска и огнезащита металлоконструкций
- **Документы и допуски (типовые):** Опыт АКЗ, работа с аппаратами безвоздушного нанесения; допуск к работам на высоте
- **Как проверить:** Объекты, на которых работал
- **Запросы для поиска:** `маляр АКЗ`, `маляр металлоконструкций`, `огнезащита металлоконструкций`
- **Ориентир по рынку:** нет данных — уточнить
- **Уточнить у компании:** Огнезащиту выполняет организация с лицензией МЧС — кто её делает

## 3. Стены, кровля, ворота

### Монтажник сэндвич-панелей

- **Что делает:** Монтаж стеновых и кровельных сэндвич-панелей, доборных элементов
- **Документы и допуски (типовые):** Допуск к работам на высоте; опыт на промышленных зданиях; работа с подъёмниками
- **Как проверить:** Фото объектов; вопросы по технологии (крепёж, уплотнение, доборы)
- **Запросы для поиска:** `монтажник сэндвич-панелей`, `монтаж сэндвич панелей бригада`
- **Ориентир по рынку:** нет данных — уточнить
- **Уточнить у компании:** Часто бригады со своим инструментом; оплата за м²

### Кровельщик (профлист / ПВХ-мембрана)

- **Что делает:** Устройство кровли, примыканий, водостоков
- **Документы и допуски (типовые):** Допуск к работам на высоте; для мембраны — опыт сварки горячим воздухом
- **Как проверить:** Фото объектов, пробный участок
- **Запросы для поиска:** `кровельщик промышленных кровель`, `кровельщик мембрана ПВХ`
- **Ориентир по рынку:** нет данных — уточнить
- **Уточнить у компании:** Тип кровли по проекту

### Промышленный альпинист

- **Что делает:** Работы на высоте без лесов и подъёмников (фасады, герметизация)
- **Документы и допуски (типовые):** Удостоверение о допуске к работам на высоте с применением систем канатного доступа
- **Как проверить:** Удостоверение, своё снаряжение
- **Запросы для поиска:** `промышленный альпинист`, `промальп`
- **Ориентир по рынку:** нет данных — уточнить
- **Уточнить у компании:** Нужен, если нет подъёмников/лесов

### Монтажник ворот, окон и дверей

- **Что делает:** Установка секционных и откатных ворот, окон, дверей
- **Документы и допуски (типовые):** Опыт монтажа; допуск к работам на высоте
- **Как проверить:** Объекты в опыте
- **Запросы для поиска:** `монтажник ворот`, `монтажник секционных ворот`, `монтажник окон`
- **Ориентир по рынку:** нет данных — уточнить
- **Уточнить у компании:** Часто монтирует поставщик — уточнить

## 4. Бетон, полы, общестрой

### Бетонщик промышленных полов

- **Что делает:** Бетонные полы с упрочнённым верхним слоем (топпинг), затирка
- **Документы и допуски (типовые):** Опыт промышленных полов, работа с затирочными машинами
- **Как проверить:** Объекты, пробная карта
- **Запросы для поиска:** `бетонщик полов`, `промышленные полы`, `топпинг`
- **Ориентир по рынку:** нет данных — уточнить
- **Уточнить у компании:** Бетонщиков уже нашли — делают ли они и полы

### Арматурщик / опалубщик

- **Что делает:** Вязка арматуры, установка опалубки
- **Документы и допуски (типовые):** Свидетельство о профессии (разряд), опыт
- **Как проверить:** Пробная смена
- **Запросы для поиска:** `арматурщик`, `опалубщик`
- **Ориентир по рынку:** нет данных — уточнить
- **Уточнить у компании:** Возможно, уже закрыто бетонной бригадой

### Каменщик

- **Что делает:** Кладка стен и перегородок (блок, кирпич)
- **Документы и допуски (типовые):** Свидетельство о профессии (разряд 3–5)
- **Как проверить:** Пробная кладка
- **Запросы для поиска:** `каменщик`
- **Ориентир по рынку:** нет данных — уточнить
- **Уточнить у компании:** Есть ли кладочные работы (АБК, КПП, вспомогательные здания)

### Плотник

- **Что делает:** Временные сооружения, опалубка, ограждения
- **Документы и допуски (типовые):** Опыт
- **Как проверить:** Пробная смена
- **Запросы для поиска:** `плотник на стройку`
- **Ориентир по рынку:** нет данных — уточнить

### Отделочник

- **Что делает:** Отделка АБК: гипсокартон, штукатурка, плитка, покраска
- **Документы и допуски (типовые):** Опыт
- **Как проверить:** Фото работ
- **Запросы для поиска:** `отделочник`, `штукатур`, `плиточник`, `монтажник ГКЛ`
- **Ориентир по рынку:** нет данных — уточнить
- **Уточнить у компании:** Нужен на поздних этапах

## 5. Внутренние инженерные системы

### Электромонтажник

- **Что делает:** Прокладка кабеля, лотки, щиты, освещение, заземление
- **Документы и допуски (типовые):** Группа по электробезопасности (для самостоятельной работы — обычно III и выше), разряд; допуск к работам на высоте
- **Как проверить:** Удостоверение по электробезопасности; опыт на промышленных объектах
- **Запросы для поиска:** `электромонтажник`, `электромонтажник промышленных объектов`
- **Ориентир по рынку:** нет данных — уточнить
- **Уточнить у компании:** Электромонтаж делаете сами или субподрядом

### Монтажник кабельных линий (кабельщик)

- **Что делает:** Прокладка кабельных линий 0,4–10 кВ, монтаж муфт
- **Документы и допуски (типовые):** Группа по электробезопасности (III–IV), опыт монтажа муфт
- **Как проверить:** Опыт, удостоверения
- **Запросы для поиска:** `кабельщик`, `монтажник кабельных линий`, `кабельщик-спайщик`
- **Ориентир по рынку:** нет данных — уточнить

### Монтажник слаботочных систем

- **Что делает:** Пожарная сигнализация и оповещение, видеонаблюдение, СКУД, сети
- **Документы и допуски (типовые):** Опыт; группа по электробезопасности; исполнитель пожарных систем — организация с лицензией МЧС
- **Как проверить:** Опыт по объектам
- **Запросы для поиска:** `монтажник слаботочных систем`, `монтажник ОПС`
- **Ориентир по рынку:** нет данных — уточнить
- **Уточнить у компании:** Обычно специализированный субподрядчик

### Монтажник вентиляции (ОВиК)

- **Что делает:** Воздуховоды, вентустановки, кондиционирование, аспирация
- **Документы и допуски (типовые):** Допуск к работам на высоте; опыт промышленной вентиляции
- **Как проверить:** Опыт по объектам
- **Запросы для поиска:** `монтажник вентиляции`, `монтажник ОВиК`
- **Ориентир по рынку:** нет данных — уточнить
- **Уточнить у компании:** Для сортировочного корпуса вентиляция — крупный раздел

### Сантехник / монтажник водоснабжения, канализации, отопления

- **Что делает:** Внутренние водопровод, канализация, отопление
- **Документы и допуски (типовые):** Опыт; сварка полипропилена/ПНД, резьбовые соединения
- **Как проверить:** Пробное задание
- **Запросы для поиска:** `монтажник систем водоснабжения`, `сантехник промышленный`, `монтажник отопления`
- **Ориентир по рынку:** нет данных — уточнить

### Монтажник систем пожаротушения

- **Что делает:** Спринклерные и дренчерные системы, противопожарный водопровод
- **Документы и допуски (типовые):** Опыт; исполнитель — организация с лицензией МЧС
- **Как проверить:** Опыт по объектам
