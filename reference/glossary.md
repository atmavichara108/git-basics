# Словарь терминов

Чтобы понимать документы компании и говорить с рабочими на одном языке.

## Объект и отрасль

| Термин | Значение |
|---|---|
| **ТКО** | Твёрдые коммунальные отходы — бытовой мусор |
| **КПО** | Комплекс по переработке (обработке) отходов: сортировка, компостирование, размещение остатков |
| **МСК / МПЗ** | Мусоросортировочный комплекс / мусороперерабатывающий завод — бытовые названия похожих объектов |
| **«Хвосты»** | Остатки после сортировки, которые нельзя переработать — их размещают на полигоне |
| **Полигон, карта полигона** | Сооружение для размещения отходов; «карта» — отдельная секция с защитным основанием (геомембрана) |
| **Компостирование** | Биологическая переработка органической части отходов на специальных площадках или в тоннелях |
| **Фильтрат** | Загрязнённая вода, стекающая с отходов; собирается и очищается — отсюда сети и очистные сооружения |
| **Регоператор** | Региональный оператор по обращению с ТКО (в СПб — АО «Невский экологический оператор», НЭО; в ЛО — АО «УК по обращению с отходами в Ленинградской области») |
| **РЭО** | ППК «Российский экологический оператор» — госкомпания, финансирует такие объекты |
| **АБК** | Административно-бытовой корпус (офисы, раздевалки, столовая) |
| **КПП, весовая** | Контрольно-пропускной пункт; весы для мусоровозов на въезде |

## Стройка и документы

| Термин | Значение |
|---|---|
| **Генподрядчик (генподряд)** | Главный подрядчик: отвечает перед заказчиком за всё строительство, нанимает субподрядчиков |
| **Субподрядчик (субподряд)** | Организация или бригада, выполняющая часть работ по договору с генподрядчиком |
| **Заказчик** | Тот, для кого строят и кто платит (здесь, вероятно, НЭО — регоператор Петербурга) |
| **СМР** | Строительно-монтажные работы |
| **ПНР** | Пусконаладочные работы — запуск и настройка оборудования и систем |
| **ППР** | Проект производства работ: как, какой техникой и в какие сроки выполняются работы |
| **РД** | Рабочая документация — чертежи, по которым строят (в отличие от проектной документации для экспертизы) |
| **КЖ** | Марка рабочих чертежей «Конструкции железобетонные»: фундаменты, стены, колонны, плиты из монолитного бетона и арматуры |
| **КМ / КМД** | Чертежи металлоконструкций / деталировочные чертежи для изготовления металлоконструкций на заводе |
| **Шифр чертежа** | Код комплекта, например `КПЭИ.1070_2.2-1.1-КЖ1`: проектировщик (КПЭИ), номер проекта (1070), объект и здание, марка и номер части (КЖ1) |
| **Изм., Рев.** | Номер изменения и номер ревизии (версии) комплекта чертежей: чем больше, тем свежее |
| **Штамп (основная надпись)** | Таблица в правом нижнем углу чертежа: объект, здание, название листа, проектировщик, стадия, подписи |
| **ВОР** | Ведомость объёмов работ: сколько чего сделать (тонны, м², м³, метры) |
| **КС-2, КС-3** | Акт о приёмке выполненных работ и справка о стоимости — по ним платят подрядчикам за объём |
| **Исполнительная документация** | Документы о том, как фактически выполнены работы (схемы, акты, журналы) |
| **Фронт работ** | Участок, готовый для работы следующей бригады. «Нет фронта» — простой |
| **Генплан** | План участка с расположением всех зданий, дорог и сетей |
| **ИТР** | Инженерно-технические работники: прорабы, мастера, инженеры |
| **ПТО** | Производственно-технический отдел (документация, объёмы, акты) |
| **Гарантийное удержание** | Часть оплаты бригаде/субподрядчику, которую удерживают до конца гарантийного срока |

## Виды работ и конструкции

| Термин | Значение |
|---|---|
| **МК** | Металлоконструкции (каркас здания: колонны, фермы, балки) |
| **ЖБК** | Железобетонные конструкции |
| **Сэндвич-панели** | Стеновые и кровельные панели «металл — утеплитель — металл» для быстровозводимых зданий |
| **Доборные элементы (доборы)** | Уголки, отливы, нащельники — закрывают стыки панелей |
| **Топпинг** | Упрочняющая сухая смесь для верхнего слоя промышленного бетонного пола |
| **Закладные** | Металлические детали, заделанные в бетон, к которым крепятся конструкции |
| **АКЗ** | Антикоррозийная защита (окраска металлоконструкций) |
| **Огнезащита** | Покрытие конструкций составами, повышающими огнестойкость |
| **ОВиК (ОВ)** | Отопление, вентиляция и кондиционирование |
| **ВК / НВК** | Водопровод и канализация (внутренние / наружные) |
| **ЭОМ** | Электрооборудование и освещение (электромонтаж) |
| **КЛ** | Кабельная линия |
| **КТП** | Комплектная трансформаторная подстанция |
| **АПС, СОУЭ, АУПТ** | Пожарная сигнализация; система оповещения при пожаре; автоматическое пожаротушение |
| **СКУД** | Система контроля и управления доступом (турникеты, пропуска) |
| **ГНБ** | Горизонтально-направленное бурение — прокладка труб под землёй без траншеи |
| **Геомембрана, геотекстиль** | Плёночный гидроизоляционный материал и нетканое полотно для защиты основания полигона |
| **ПНД / ПЭ-трубы** | Полиэтиленовые трубы (сети водопровода, канализации); сваривают встык или электромуфтами |

## Сварка и допуски

| Термин | Значение |
|---|---|
| **НАКС** | Национальное агентство контроля сварки — аттестует сварщиков для ответственных работ |
| **СК, НГДО, ОХНВП, КО** | Группы технических устройств в аттестации НАКС: СК — строительные конструкции; НГДО — нефтегазодобывающее оборудование; ОХНВП — химические и нефтеперерабатывающие производства; КО — котельное оборудование |
| **РД, МП, РАД** | Способы сварки: ручная дуговая (электроды); механизированная в защитном газе (полуавтомат); ручная аргонодуговая |
| **Разряд** | Уровень квалификации рабочего (обычно 2–6; чем выше — тем сложнее работы) |
| **Промальп** | Промышленный альпинизм: работа на высоте на верёвках, без лесов и подъёмников |
| **СИЗ** | Средства индивидуальной защиты: каска, очки, перчатки, страховочная привязь и т. д. |

## Найм и режим работы

| Термин | Значение |
|---|---|
| **Вахта 60/30** | 60 дней работы подряд, затем 30 дней отдыха (аналогично 30/15, 45/15 и т. п.) |
| **График 7/0, 6/1** | Работа без выходных / шесть дней работы и один выходной в неделю |
| **«На руки» / «до вычета НДФЛ»** | Сумма после удержания налога 13% / сумма до удержания |
| **Сдельная оплата** | Оплата за объём (за тонну, м², метр), а не за время |
| **ТД** | Трудовой договор (по Трудовому кодексу: отпуск, больничные, стаж) |
| **ГПХ** | Гражданско-правовой договор (подряд, услуги): без отпуска и больничных |
| **Самозанятый** | Физлицо на налоге на профессиональный доход; работает по договору, сам платит налог |
| **Простой** | Время, когда работать нельзя не по вине работника (нет материала, погода, техника) |
| **Пробная смена** | Первая смена для проверки квалификации — важно заранее знать, оплачивается ли она |
| **Патент** | Разрешение на работу для иностранцев из безвизовых стран вне ЕАЭС |
| **ЕАЭС** | Евразийский экономический союз: граждане Армении, Беларуси, Казахстана, Кыргызстана работают без патента |
