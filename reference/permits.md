# Удостоверения и допуски: шпаргалка для отбора

**Назначение:** быстро понять по телефону, есть ли у кандидата нужные «корочки», и что попросить
прислать на фото. Требования конкретного объекта задают компания и заказчик (вопросы 5.1–5.4,
документ Д12) — эта шпаргалка их не заменяет.

## Общее правило

- Просить **фото удостоверения целиком** (разворот): ФИО, профессия/разряд, кем выдано, дата,
  отметки о проверке знаний. Смотреть срок действия и дату последней проверки.
- «Корочки» бывают купленными. Реальный опыт проверяется вопросами по технологии и пробной сменой.
- Если удостоверения нет, но человек опытный — это вопрос к компании: учит ли она за свой счёт (вопрос 11.4).

## Основные документы по специальностям

| Документ | Кому нужен | Что проверять |
|---|---|---|
| **Аттестация НАКС** (удостоверение сварщика) | Сварщикам на ответственных конструкциях | Группа технических устройств (для металлоконструкций зданий — **СК**), способ сварки (**РД** — ручная дуговая, **МП** — полуавтомат в защитном газе, **РАД** — аргонодуговая), срок действия. Удостоверение можно проверить в реестре на сайте НАКС (naks.ru) |
| **Свидетельство о профессии с разрядом** | Монтажникам, сварщикам, слесарям, бетонщикам и др. | Профессия, разряд (чем выше разряд — тем сложнее работы) |
| **Удостоверение стропальщика** | Всем, кто цепляет грузы к крану (часто монтажникам) | Дата последней проверки знаний (обычно ежегодно) |
| **Допуск к работам на высоте** | Монтажникам МК и панелей, кровельщикам, электромонтажникам, вентиляционщикам | Группа допуска (1 — работает под руководством; 2 — бригадир, мастер; 3 — ответственные). Для промальпа — отдельный допуск с канатным доступом |
| **Группа по электробезопасности** | Электромонтажникам, наладчикам, кабельщикам; также сварщикам и работающим с электроинструментом | Группа (II–V) и дата проверки. Для самостоятельной электромонтажной работы обычно нужна III и выше |
| **Удостоверение машиниста крана** | Крановщикам (автокран, гусеничный, башенный) | Вид крана; для автокрана — ещё водительские права кат. «C» |
| **Удостоверение тракториста-машиниста** (Гостехнадзор) | Машинистам экскаватора, бульдозера, погрузчика, катка, грейдера | Открытые категории: гусеничные машины — «E», колёсные — «C»/«D» (зависит от мощности) |
| **Водительское удостоверение** | Водителям самосвалов («C», тягач — «CE»), автобусов («D», «D1») | Категории, стаж |
| **Удостоверение газорезчика** | Газорезчикам | Дата выдачи и проверки знаний |
| **Медосмотр / медкнижка** | Всем при приёме (медосмотр организует работодатель) | Кто оплачивает и где проходить — вопрос 5.4 |

## Документы организаций (не рабочих)

Некоторые виды работ может выполнять только **организация с лицензией** — например, монтаж систем
пожарной сигнализации и пожаротушения, огнезащита конструкций (лицензия МЧС). Если компания ищет под
такие работы бригаду — это должен быть субподрядчик с лицензией, а не отдельные рабочие.

## Что спросить по телефону (быстрый чек)

1. Какие удостоверения есть и когда последняя проверка знаний?
2. Для сварщика: НАКС есть? Какая группа и способы? До какого числа действует?
3. Для работ на высоте: какая группа допуска?
4. Для электриков: какая группа по электробезопасности?
5. Для машинистов: какие категории открыты, на какой технике работал последние 2 года?
6. Можете прислать фото удостоверений в мессенджер?
