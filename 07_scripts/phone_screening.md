# Скрипт первого звонка

Цель звонка — за 5–10 минут понять: **подходит ли человек**, **устраивают ли его условия** и
**когда он может выйти**. Условия озвучиваются только по согласованной карточке вакансии
(`05_vacancies/`), ответы на частые вопросы — в [`faq_candidates.md`](faq_candidates.md).

## A. Звонок рабочему

1. **Знакомство.** «Здравствуйте, {имя}! Меня зовут {имя}, я по вашему отклику на вакансию
   {специальность} — объект под Петербургом. Удобно пару минут поговорить?»
2. **Опыт** (сначала спрашиваем, потом рассказываем):
   - Где работали последние 1–2 года? Какие объекты, что делали сами?
   - Какой разряд? Какие удостоверения есть и когда последняя проверка знаний?
   - 2–3 вопроса из раздела C по специальности.
3. **Условия — коротко:** деньги (сколько, за что, на руки или нет, как часто выплаты), график,
   жильё / питание / дорога, оформление. Спросить: «Как вам такие условия?»
4. **Вопросы кандидата** → ответы по FAQ. Не знаешь ответа — не придумывать: «уточню и перезвоню до {время}».
5. **Готовность:**
   - Откуда поедете? Когда можете выйти?
   - Документы при себе: паспорт, СНИЛС, ИНН, удостоверения. Для иностранцев — вопросы из
     [`reference/migration.md`](../reference/migration.md), раздел 4.
   - Можете прислать фото удостоверений в мессенджер?
6. **Следующий шаг — конкретно:** «Пришлите фото удостоверений в {мессенджер} сегодня, я передам
   прорабу, ответ — до {дата}». Записать итог звонка (раздел F).

## B. Разговор с бригадиром

1. Сколько человек в бригаде, какие специальности и удостоверения у каждого?
2. Последние 2–3 объекта: что делали, какой объём, для кого? Можно ли позвонить прошлому заказчику?
3. Инструмент и оснастка свои? Техника (подъёмники, сварочные аппараты)?
4. Как работаете: ИП / ООО / самозанятые / по трудовому договору? С НДС или без?
5. Какие расценки обычно берёте (₽/т, ₽/м², ₽/м)? Нужен ли аванс?
6. Когда можете зайти и за сколько сделаете объём {…}?
7. Нужно ли жильё и на сколько человек?
8. Пришлёте фото и видео прошлых объектов?

## C. Проверка опыта по специальностям

Задавать 2–3 вопроса. Правильный ответ — не обязательно слово в слово: опытный человек отвечает
уверенно и конкретно, «корочник» путается и уходит в общие слова.

| Специальность | Вопрос | Что обычно отвечает опытный |
|---|---|---|
| **Монтажник МК** | Какие здания монтировали? Какой был пролёт, высота, вес элементов? | Конкретные объекты: ангары, цеха, склады; цифры пролётов и высот |
| | Как выставляете колонну по вертикали? | Теодолит или отвес, регулировка на анкерах, подкладки / клинья |
| | Работали с высокопрочными болтами? Как затягиваете? | Тарированным (динамометрическим) ключом до заданного момента |
| **Сварщик** | НАКС: какая группа, способы, до какого числа? Номер удостоверения? | Например: СК, РД и МП, срок действия; номер — проверить в реестре НАКС |
| | Какими электродами варите металлоконструкции? | Для ответственных конструкций — УОНИ-13/55 |
| | В каких положениях варите? | Нижнее, вертикальное, потолочное — опытный называет все |
| | Полуавтомат: какая проволока и газ? | Например, проволока Св-08Г2С, углекислота или смесь |
| **Стропальщик** | Когда последняя проверка знаний? | Конкретная дата, не больше года назад |
| | Как проверяете строп перед работой? | Осмотр: бирка, целостность, нет порванных прядей и деформаций; бракованный — не использовать |
| **Машинист экскаватора / бульдозера** | Какие категории открыты? На какой технике работали последние 2 года? | Категории («E» для гусеничной, «C»/«D» для колёсной), марки и вес машин |
| | Работали по отметкам — с нивелиром, лазером, GPS? | Да, копал котлованы и траншеи «в отметку» по геодезисту |
| **Машинист крана** | Какой вид крана и грузоподъёмность в удостоверении? На каких кранах работали? | Вид и тоннаж совпадают с объектом; опыт монтажа металлоконструкций |
| **Электромонтажник** | Какая группа по электробезопасности? | Обычно III и выше; дата проверки |
| | Что монтировали: лотки, кабели какого сечения, щиты, освещение? | Конкретика по объектам и сечениям |
| | Опрессовка наконечников, замеры мегаомметром — делали? | Да; объясняет, зачем замер изоляции |
| **Монтажник сэндвич-панелей** | Стеновые или кровельные? Толщина, длина, вертикальный или горизонтальный монтаж? | Цифры и особенности обоих вариантов |
| | Чем поднимали панели? | Кран с вакуумным захватом или траверсой, подъёмник |
| **Кровельщик (мембрана)** | Какие мембраны, чем варите? | ПВХ или ТПО; автомат для горячего воздуха и ручной фен |
| | Примыкания, воронки, механическое крепление — делали? | Да, с деталями |
| **Подсобный рабочий** | Работали на стройке? Какие работы? | Любой реальный опыт — плюс |
| | Физическая работа на улице, в том числе зимой, — нормально? | Спокойное «да» |

## D. Тревожные признаки

- Не может назвать ни одного объекта или путается в своей же технологии.
- Удостоверения «есть, но дома», фото прислать не может.
- Везде работал по 1–2 недели — спросить почему.
- Первый и главный вопрос — аванс «сразу и наличными».
- Отказывается от пробной смены или проверки.
- Признаки нетрезвости на звонке или встрече.
- Бригада: нет фото объектов, нет рекомендаций, просят крупную предоплату.

## E. Частые возражения

_Ответы заполнятся после ответов компании; ниже — как себя вести._

| Возражение | Как отвечать |
|---|---|
| «Мало платят» | Уточнить, с чем сравнивает: на руки или до налога, сколько часов, учтены ли жильё и питание. Если разница реальная — записать и передать компании (вопрос 8.11) |
| «Далеко, неудобно ехать» | Рассказать про доставку и жильё (вопросы 10.1, 10.4) |
| «А не кинут?» | ИНН для проверки, тип договора, график выплат (вопросы 2.1, 6.1, 8.2) |
| «Нужен аванс сразу» | Как устроены авансы в компании (вопрос 8.2); не обещать сверх этого |
| «Можно без оформления?» | Как оформляет компания (вопрос 6.1) — только это |
| «Подумаю» | Договориться о конкретном времени повторного звонка, прислать условия сообщением |

## F. Что записать после звонка

Дата · источник (Авито / hh / Telegram / сарафан…) · специальность · бригада или один · опыт коротко ·
удостоверения (есть фото или нет) · откуда едет · когда может выйти · гражданство (для оформления) ·
итог (подходит / не подходит / думает) · следующий шаг и дата.

Записи — в папку `06_candidates/` (появится к запуску поиска). Только то, что нужно для подбора:
паспортные данные и сканы документов кандидатов в репозиторий не кладём.
