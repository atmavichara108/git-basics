## 2026-09-24 — старт проекта

**Сделано**

- Репозиторий очищен от старого содержимого (заготовка HTML/CSS) и перестроен под задачу подбора.
- Создана структура: входящие → компания → вопросы → специальности → каналы поиска + справочники и скрипты.
- Опросник для компании v1: 91 вопрос в 15 блоках с приоритетами + короткий список из 15 вопросов
  для первого звонка. Отдельно — перечень из 19 документов для запроса.
- Word-версия опросника (с колонкой для ответов и перечнем документов) и Excel-заявка на 46 типовых
  специальностей с выпадающими списками — собираются скриптом `tools/build_docs.py` из исходников.
- Исследование открытых источников:
  - объект — вероятно, КПО «Рахья» (Всеволожский район; старт в апреле 2026, завершение — IV кв. 2026);
  - рыночные ставки по монтажникам МК, сварщикам НАКС, подсобникам в СПб/ЛО;
  - правила для иностранцев: ЕАЭС без патента; для патентников важен регион патента (соглашение СПб–ЛО
    о едином патенте — статус не подтверждён); в ЛО на начало 2026 запрет для патентников только в такси;
  - стоимость каналов: Авито — оплата за отклики, hh.ru — платно, «Работа России» — бесплатно.
- Скрипт `tools/extract_text.py` для разбора документов (PDF, сканы, DOCX, XLSX/XLS, DOC, текст).
