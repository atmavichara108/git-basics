# Шаблоны объявлений и сообщений

Данные в `{фигурных скобках}` берутся **только из согласованной карточки вакансии**
(`05_vacancies/<специальность>.md`). Чего нет в карточке, то в объявлении не обещаем.

## Правила

- Одна вакансия — одна специальность.
- В заголовке — специальность и главный плюс; в первых строках — деньги, график, жильё и дорога.
- Сумма — с пометкой, «на руки» это или до вычета НДФЛ, и за что (смена / час / месяц / объём).
- Никаких требований по полу, возрасту, национальности, месту жительства — только квалификация и удостоверения.
- Реальные фото объекта и жилья.
- Не обещать того, чего компания не подтвердила: лишнее обещание = уход в первую неделю.

## 1. Авито Работа — вакансия

**Заголовок:** {Специальность} — {главный плюс}

```text
{Работодатель} приглашает {специальность} на строительство {объект одной фразой} ({место}).

Условия:
— {ставка} ₽ {за смену / в час / в месяц} {на руки / до вычета НДФЛ}
— выплаты {частота}, первая — через {N} дней
— {вахта N/N, смены по N часов / ежедневные выезды, график}
— жильё: {условия}; питание: {условия}
— доставка до объекта: {как}
— проезд для приезжих: {условия компенсации}
— оформление: {тип договора}
— спецодежда и СИЗ: {условия}

Задачи:
— {обязанность 1}
— {обязанность 2}
— {обязанность 3}

Требования:
— опыт {…}, разряд {…}
— удостоверения: {…}

Как устроиться: напишите в чат или позвоните. Пришлите фото удостоверений — ответим {срок}.
```

## 2. hh.ru — вакансия

```text
Название: {Специальность} ({вахта / ежедневно})

Обязанности:
• {обязанность 1}
• {обязанность 2}
• {обязанность 3}

Требования:
• опыт работы {…} на {промышленных объектах / аналогичных работах}
• удостоверения: {…}

Условия:
• {ставка} ₽ {за что} {на руки / до вычета НДФЛ}, выплаты {частота}
• {график, режим}
• {жильё, питание, доставка, проезд}
• {оформление}
• спецодежда и СИЗ {условия}
• объект: {что строим}, {место}; работа до {срок}, {перспектива}

Ключевые навыки: {из «Запросов для поиска» в каталоге специальностей}
```

## 3. Telegram / VK — короткий пост

```text
🔧 Требуются {специальности} — {N} чел.
📍 {место} — {объект одной фразой}
💰 {ставка} ₽ {за что} {на руки / до НДФЛ}, выплаты {частота}
📅 {вахта N/N / ежедневно}, смены по {N} ч
🏠 {жильё} · 🍲 {питание} · 🚌 {доставка}
📄 {оформление}
✅ Нужно: {удостоверения}
✉️ {контакт}
```

## 4. Первое сообщение бригаде (найденной на Авито Услугах, в Telegram и т. п.)

```text
Здравствуйте, {имя}! Увидел(а) ваше объявление о {вид работ}. Ищу бригаду на промышленный объект
под Петербургом: {что строим}. Объём — {N т металлоконструкций / N м² панелей / …}, старт {дата}.
Условия: {расценки или порядок оплаты}, {жильё}, работаем через {ИП / ООО / самозанятых / трудовой договор}.
Если интересно — подскажите, сколько вас человек, какие удостоверения и есть ли фото прошлых объектов.
```

## 5. Сообщение для «сарафана» (работающим на объекте, знакомым)

```text
На объект под Петербургом ищем: {специальности}. {Ставки коротко}, {жильё / питание / доставка}.
{Если есть премия за приведённого: «За каждого, кто выйдет и отработает N смен, — {сумма}».}
Если есть знакомые — пусть пишут или звонят: {контакт}.
```
