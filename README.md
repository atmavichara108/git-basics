# Подбор рабочих для строительства мусороперерабатывающего комплекса (Ленобласть)

Рабочий репозиторий проекта по подбору персонала для строительной компании, которая строит
комплекс по переработке отходов в Ленинградской области. Задача — найти через открытые источники
(Авито, hh.ru, «Работа России», Telegram, VK и др.) нужных специалистов и целые бригады.

Первый шаг — собрать у компании всю информацию, чтобы понимать, **кого и где искать**, и **компетентно
отвечать** рабочим и бригадирам. Для этого подготовлены опросник, перечень документов и таблица-заявка.

## Следующие шаги

1. **Сделать репозиторий приватным** (GitHub → Settings → General → Danger Zone → Change repository
   visibility → Private). Сейчас он публичный, а дальше здесь будут документы компании и данные кандидатов.
2. **Загрузить документы компании** → разбор, конспекты, обновление профиля компании и опросника (блок 15).
3. **Отправить компании** опросник и таблицу-заявку (или пройти короткий список по телефону).
4. По ответам: карточки вакансий, тексты объявлений, скрипт звонка и FAQ для кандидатов, запуск поиска.

## Правила ведения

- **Вся информация — здесь, а не «в голове» или в переписке.** Ответы компании, выводы, решения — в файлы.
- **У каждого факта — источник и статус:** ✅ подтверждено · 🔶 гипотеза · ❔ нет данных.
- **Исходники и сборки.** Редактируются `.md` и `.csv`; файлы `.docx` / `.xlsx` и `roles_catalog.md`
  собираются скриптом — руками их не править.
- **Персональные данные кандидатов** — только в приватном репозитории и в минимальном объёме.
- Каждый рабочий шаг — запись в [`JOURNAL.md`](JOURNAL.md).

## Команды

```bash
bash tools/setup.sh              # установить зависимости (один раз)
python3 tools/extract_text.py    # извлечь текст из документов в 00_inbox
python3 tools/build_docs.py      # пересобрать voprosy_kompanii.docx, zayavka_na_podbor.xlsx, roles_catalog.md
```
