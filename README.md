# Подбор рабочих для строительства мусороперерабатывающего комплекса (Санкт-Петербург / Ленобласть)

Рабочий репозиторий проекта по подбору персонала для строительной компании, которая строит
комплекс по переработке отходов под Петербургом (по шифру чертежей — почти наверняка КПО «Новосёлки» в Левашово). Задача — найти через открытые источники
(Авито, hh.ru, «Работа России», Telegram, VK и др.) нужных специалистов и целые бригады.

Первый шаг — собрать у компании всю информацию, чтобы понимать, **кого и где искать**, и **компетентно
отвечать** рабочим и бригадирам. Для этого подготовлены опросник, перечень документов и таблица-заявка.

## Следующие шаги

Подробно — в [`PLAN.md`](PLAN.md).

1. **Загрузить 6 PDF-чертежей через GitHub** в папку `00_inbox` рабочей ветки
   ([прямая ссылка](https://github.com/atmavichara108/git-basics/upload/arena/01a0d2fa-git-basics/00_inbox)). Через чат файлы дважды не дошли.
2. **Не дожидаясь разбора** — созвониться с компанией по короткому списку и отправить таблицу-заявку
   (готовое сообщение: [`02_questions/cover_message.md`](02_questions/cover_message.md), вариант 1).
3. **Отправить полный опросник** (вариант 2 сообщения) — после разбора документов.
4. По ответам: карточки вакансий, объявления, заполненный FAQ, запуск поиска.
5. В конце работ — сделать репозиторий приватным.

## Как работа попадает в `main`

Агент работает в ветке `arena/01a0d2fa-git-basics`. Готовые порции приходят в `main` через pull request:
владелец открывает его на GitHub и нажимает **Merge pull request**.

## Правила ведения

- **Вся информация — здесь, а не «в голове» или в переписке.** Ответы компании, выводы, решения — в файлы.
- **У каждого факта — источник и статус:** ✅ подтверждено · 🔶 гипотеза · ❔ нет данных.
- **Исходники и сборки.** Редактируются `.md` и `.csv`; файлы `.docx` / `.xlsx` и `roles_catalog.md`
  собираются скриптом — руками их не править.
- **Персональные данные кандидатов** — в минимальном объёме: только то, что нужно для подбора.
- Каждый рабочий шаг — запись в [`JOURNAL.md`](JOURNAL.md).

## Команды

```bash
bash tools/setup.sh              # установить зависимости (один раз)
python3 tools/extract_text.py    # извлечь текст из документов в 00_inbox
python3 tools/build_docs.py      # пересобрать voprosy_kompanii.docx, zayavka_na_podbor.xlsx, roles_catalog.md
```
