# Подбор рабочих для строительства мусороперерабатывающего комплекса (Санкт-Петербург / Ленобласть)

Рабочий репозиторий проекта по подбору персонала для строительной компании, которая строит
комплекс по переработке отходов под Петербургом (объект подтверждён по штампу чертежей: КПО «Новоселки»,
производственный корпус, Левашово). Задача — найти через открытые источники
(Авито, hh.ru, «Работа России», Telegram, VK и др.) нужных специалистов и целые бригады.

Первый шаг — собрать у компании всю информацию, чтобы понимать, **кого и где искать**, и **компетентно
отвечать** рабочим и бригадирам. Для этого подготовлены опросник, перечень документов и таблица-заявка.

## Следующие шаги

Подробно — в [`PLAN.md`](PLAN.md).

1. **Не дожидаясь ответов** — созвониться с компанией по короткому списку и отправить таблицу-заявку
   (готовое сообщение: [`02_questions/cover_message.md`](02_questions/cover_message.md), вариант 1).
2. **Отправить полный опросник** (вариант 2 сообщения) — он уже учитывает чертежи КЖ: закрытые вопросы
   отмечены, добавлен блок 15 с уточнениями (ТЭП Иваново, сваи, оборудование, зимнее бетонирование).
   Заодно запросить недостающие комплекты (Д20: КЖ4 со сваями, КМ, ИГИ).
3. По ответам: карточки вакансий, объявления, заполненный FAQ, запуск поиска.
4. В конце работ — сделать репозиторий приватным.

Новые документы кладём в [`00_inbox/`](00_inbox/) ([загрузка через GitHub](https://github.com/atmavichara108/git-basics/upload/main/00_inbox)) —
разбираю по описанной там схеме.

## Правила ведения

- **Вся информация — здесь, а не «в голове» или в переписке.** Ответы компании, выводы, решения — в файлы.
- **У каждого факта — источник и статус:** ✅ подтверждено · 🔶 гипотеза · ❔ нет данных.
- **Исходники и сборки.** Редактируются `.md` и `.csv`; файлы `.docx` / `.xlsx` и `roles_catalog.md`
  собираются скриптом — руками их не править.
- **Персональные данные кандидатов** — в минимальном объёме: только то, что нужно для подбора.
- Каждый рабочий шаг — запись в [`JOURNAL.md`](JOURNAL.md).
